# 🚀 Prompt Optimizer

> Turn simple ideas into powerful, clear, and AI-ready prompts.

**Prompt Optimizer** is a simple tool designed to transform rough, unclear, or incomplete prompts into more structured and effective prompts for AI tools.

Instead of spending time rewriting the same prompt again and again, you can provide your original idea and let Prompt Optimizer improve its clarity, structure, context, and instructions.

---

## ✨ Features

* 🧠 **Prompt Enhancement** — Improve unclear or incomplete prompts
* ✍️ **Better Structure** — Organize instructions into a clear format
* 🎯 **Clear Intent** — Preserve the original purpose of your prompt
* ⚡ **Fast Optimization** — Turn rough ideas into usable prompts quickly
* 🤖 **AI-Friendly Prompts** — Create prompts that are easier for AI models to understand
* 📋 **Easy Copy** — Copy the optimized prompt and use it anywhere
* 🎨 **Clean & Simple UI** — Designed to keep the experience simple and distraction-free

---

## 💡 Why Prompt Optimizer?

Writing a good prompt can sometimes be harder than the actual task.

A simple request like:

> "Make a website for my business."

can be transformed into a much more useful instruction containing:

* The role of the AI
* The exact objective
* Important context
* Functional requirements
* Design requirements
* Technical constraints
* Expected output format

The goal is **not to make prompts unnecessarily longer**.

The goal is to make them **clearer, more specific, and more useful** while preserving the user's original intention.

## 🧪 Example

### Before

```text
Make me a modern portfolio website.
```

### After

```text
Create a modern, responsive personal portfolio website for a frontend developer.

Requirements:
- Use a clean and premium visual design
- Create responsive layouts for desktop, tablet, and mobile
- Include Home, About, Skills, Projects, and Contact sections
- Use smooth animations without affecting performance
- Maintain strong typography and visual hierarchy
- Keep the UI simple, professional, and easy to navigate

Return the complete implementation with clean, well-structured code.
```

The optimized prompt provides more context while keeping the original goal intact.
